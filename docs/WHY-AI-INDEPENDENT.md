# Why Chess-Publisher Web Is AI-Independent

Chess-Publisher Web must not depend on memory held by one conversation or one vendor's coding agent.

Durable project knowledge belongs in version control:
- architecture decisions;
- protected components;
- upstream versions/commits;
- regression fixtures;
- feature-parity baseline;
- current blockers;
- next task;
- release criteria.

This allows Google AI Studio, Junie, Codex, Cursor, Claude, or a human developer to continue safely from the same repository state.
