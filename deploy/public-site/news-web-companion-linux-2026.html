Meet WEB Companion.

The Chess-Publisher Web section has a new identity. WEB Companion is the browser companion for organizers and arbiters who need essential tournament work away from the main desktop computer — including mobile use directly from the tournament hall.

What it is

A companion — not a browser copy of the entire desktop application.

Chess-Publisher Desktop remains the complete local tournament environment. WEB Companion focuses on the tasks that gain the most from mobility and secure browser access.

That separation keeps the full tournament engine and desktop-only workflows where they belong, while making organizer work available on more devices.

Progressive Web App

No separate app-store download is required.

WEB Companion includes the web-app manifest and service-worker foundation needed for installable PWA behavior on supported devices. That means the same Chess-Publisher web workspace can be reached from the browser or opened from the device home screen.

Important: installability does not mean every tournament function moves into the browser. Pairing-engine, standings/tie-break, TRF, DGT and other desktop engine workflows remain part of the full desktop application.

🐧LinuxIn development

Chess-Publisher is coming to Linux.

Windows remains the current stable desktop platform, while development toward Linux compatibility is now part of the Chess-Publisher roadmap. The goal is to bring the full desktop tournament environment to Linux without weakening the protected pairing, TRF, Chess-Results and tournament-data workflows.

Linux builds will be announced when compatibility and regression testing are ready for public testing.
